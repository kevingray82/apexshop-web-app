## Getting Started

First, download the repository and move into its directory:

```bash
git clone https://github.com/kevingray82/apexshop-web-app.git
cd REPO
```

The main HTML file may be opened directly in a current web browser. Alternatively, run a local HTTP server from the project directory:

```bash
python -m http.server 8000
```

Open the local preview at:

```text
http://localhost:8000
```

You may also use the [latest build page](https://kevingray82.github.io/apexshop-web-app/) to access the hosted version.
